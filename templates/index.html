Getting Started

  1. Create Your Portfolio

    Open Portfolios and select New Portfolio. Enter a name, then select Create Portfolio.

    Create Portfolio

  2. Add Your Holdings

    Open Holdings and select Add Holding. Enter a ticker, number of shares, purchase price, and manually recorded current price. Save to add it.

    {{ 'Add Holding' if selected_portfolio else 'Create a Portfolio First' }}

  3. Review Your Investments

    Use the dashboard for an overview, Charts for visual allocations, and Info for detailed statistics.

    View Dashboard
